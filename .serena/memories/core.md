# Project map
- The workspace groups independent Berkeley Pacman course assignments. Each `pjN/` is its own script root, with its own imports and grader. `pj1`–`pj3` duplicate names such as `util.py`, `game.py`, and `pacman.py`. Resolve symbols within the relevant folder and run commands from that folder.
- Search interfaces, agents, and question coverage: `mem:pj1/core`.
- Multiagent search, depth rules, and expansion-sensitive grading: `mem:pj2/core`.
- MDP, Gridworld, value iteration and Q-learning interfaces: `mem:pj3/core`.
- PyTorch training, datasets and question coverage: `mem:pj5/core`.
- Runtime and dependency boundaries: `mem:tech_stack`. PowerShell and executable examples: `mem:suggested_commands`. Targeted and full autograder checks: `mem:task_completion`. Grader-facing signatures, fixtures and shared utilities: `mem:conventions`.
